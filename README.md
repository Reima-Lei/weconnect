# WeConnect 💬

A real-time chat application built with the MERN stack, designed to make communication seamless through instant messaging and a responsive user interface.

## ✨ Features

- 💬 Real-time messaging
- 👤 User authentication
- 📱 Responsive user interface
- ⚡ Instant message updates
- 🔐 Secure authentication and protected routes
- 🌐 Full-stack architecture with separate frontend and backend

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Real-Time Communication
- Socket.IO

### Tools
- Git & GitHub
- npm
